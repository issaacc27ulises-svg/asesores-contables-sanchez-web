# Asesores Contables Sánchez

Página web inicial optimizada para SEO local en Manzanillo, Colima.

## Antes de publicar
1. Cambia `TU-DOMINIO-AQUI.com` en `index.html`.
2. Cambia `TU_NUMERO` y `TU_TELEFONO`.
3. Reemplaza el logo si tienes una versión con fondo transparente.
4. Publica en Vercel o GitHub Pages.
5. Después configura Google Search Console y Google Business Profile.
